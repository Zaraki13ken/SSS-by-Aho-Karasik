# SSS by Aho-Karasik(Search Substrings in String)

Практическая работа №2. Консольная утилита для поиска всех вхождений набора подстрок в строке или файле с использованием алгоритма Ахо-Корасик.

## Возможности
- Поиск одной или нескольких подстрок.
- Учёт/неучёт регистра.
- Поиск с начала или с конца.
- Ограничение количества найденных вхождений.
- Чтение текста из файла или из аргумента командной строки.
- Цветной вывод результатов с ограничением в 10 строк.
- Логирование времени выполнения (декоратор).

## Стек
- Python 3.10+

## Установка
```bash
git clone https://github.com/Zaraki13ken/simple-mp.git
cd simple-mp
```

## Использование
- **Поиск в строке**
    ```bash
    python main.py --string "ababbababa" --substring aba bba
    ```
- **Поиск в файле**
    ```bash
    python main.py --file любой_текст.txt --substring подстроки через пробел --count 5
    ```
## Аргументы командной строки
- **--string** - Исходная строка для поиска
- **--file** - Путь до файла (альтернатива --string)
- **--substring** - Одна или несколько подстрок (обязательный)
- **--metod** - ```first``` (по умолчанию) или ```last```
- **--count** - Максимальное количество совпадений
- **--case** - Учитывать регистр (по умолчанию не учитывается)

## Пример
- **Ввод:**
    ```bash
    python main.py --string "ababbababa" --substring aba bba
    ```
- **Вывод:**
    ```bash
    [TIME] search выполнено за 0.000123 сек.
    Результат: {'aba': (0, 5, 7), 'bba': (3,)}

    Подсветка:
    ababbababa
    ```
